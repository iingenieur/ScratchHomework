# 마리오 - 좌우 이동 (Movement)

## 함수
`mechanics.mario_movement(m, V=None, speed=5, with_direction=True, walk_mode="next")`

## 역할
좌우 화살표 키로 수평 이동 + 걷기 애니메이션

## 동작
- 오른쪽/왼쪽 화살표 → X +=/-= speed
- `with_direction=True` → 이동 방향으로 스프라이트 회전 (좌우 반전)
- **점프 중(점프중==1)이면 걷기 애니메이션 스킵** → 점프 코스튬 유지
- **바닥에서(점프중==0) 이동 시 걷기 코스튬 순환** (next_costume)
- **무적 상태에서도 이동 가능** — 이동은 무적/피격과 무관

## 걷기 스프라이트 (코스튬 순서)
| 인덱스 | 코스튬 이름 | 파일 | 용도 |
|--------|------------|------|------|
| 0 | 걷기1 | `mario/mario3_walk_1.png` | 기본 자세 / 걷기 프레임 1 |
| 1 | 걷기3 | `mario/mario3_walk_3.png` | 걷기 프레임 2 |
| 2 | 걷기4 | `mario/mario3_walk_4.png` | 걷기 프레임 3 |
| 3 | 걷기5 | `mario/mario3_walk_5.png` | 걷기 프레임 4 |
| 4 | 걷기6 | `mario/mario3_walk_6.png` | 걷기 프레임 5 |

점프 코스튬은 코스튬 리스트에 포함하지 않음.
점프 시작/착지 시 `costume("점프1")` / `costume("걷기1")`으로 직접 전환.
→ `next_costume` 순환에 점프 코스튬이 포함되지 않아 깜빡임 없음.

**주의:** 점프 코스튬은 마리오 스프라이트의 코스튬 리스트 **마지막**에 배치하되,
걷기 순환은 인덱스 0~4만 사용. `next_costume`이 인덱스 4에서 5(점프)로
넘어가지 않도록, 걷기 코스튬 5개만 등록하고 점프 코스튬은 별도 등록.

## 파라미터
| 이름 | 기본값 | 설명 |
|------|--------|------|
| `V` | `None` | 변수 딕셔너리 (점프중 체크용) |
| `speed` | `5` | 이동 속도 (px/frame) |
| `with_direction` | `True` | 방향 전환 여부 |
| `walk_mode` | `"next"` | 애니메이션 모드 |

## 사용 변수
`점프중` (읽기 전용, 애니메이션 조건)
