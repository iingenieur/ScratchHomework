# 마리오 - 파이어 파워업 (Fire Power-up)

Stage2A 전용. 파이어 꽃을 먹으면 파이어 마리오로 변신, Z키로 파이어볼 발사 가능.

## 변수
- `파이어` (0/1) — Stage2A 전용. 0: 일반 마리오, 1: 파이어 마리오. 게임 시작/재시작 시 0으로 초기화.

## 파이어 꽃 (스프라이트)
- 초기 상태: `hide`
- "꽃등장" 브로드캐스트 수신:
  1. `goto(?블록 x, ?블록 y + 20)` — ?블록 바로 위
  2. `show()`
- 마리오 접촉 시 (꽃 측 forever):
  - `touching(Mario)` 감지 → `broadcast "파이어변신"` → `hide()`

## 마리오 변신 (마리오 측 별도 스크립트)
- "파이어변신" 브로드캐스트 hat:
  1. `파이어 = 1`
  2. 코스튬 색조 변경 — 단순 구현: 코스튬은 그대로 두고 변수만 토글. (시각 표현은 차후 강화 가능)

## 파이어볼 발사
- 마리오 forever 안에 Z키 조건 추가:
  - 조건: `key_pressed(z)` AND `파이어 == 1` AND 게임상태 가드
  - 처리: `broadcast "발사"` → 파이어볼 스프라이트가 마리오 위치에서 출발

## 파이어볼 스프라이트
- Stage 3 `svg_fireball()` 재사용 — 작은 빨간 원
- "발사" hat:
  1. `goto(Mario_x, Mario_y)` — 마리오의 현재 위치
  2. `show()`
  3. `glide(0.5, Mario_x + 300, Mario_y)` — 오른쪽으로 발사
  4. `hide()`
- forever 안에서 `touching(Turtle1/Turtle2/Spiky1/Spiky2)` 감지 시 해당 적 측 "맞음" broadcast 발송 → 적 hide

## 지속 시간
**무한** — Stage 시작/재시작 전까지 유지. 게임 재시작 broadcast("스테이지2A") 수신 시 `파이어 = 0` 리셋.

## 사용 변수 / 브로드캐스트
- 변수: `파이어`
- 브로드캐스트: `꽃등장`, `파이어변신`, `발사`, `맞음1`/`맞음2`/`맞음3`/`맞음4` (적별로)
