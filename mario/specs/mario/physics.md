# 마리오 - 물리 (Physics)

## 함수
`mechanics.mario_physics(m, V, ground_y=GY, landing_costume=None)`

## 역할
매 프레임 중력 적용 + 바닥 착지 처리

## 동작
1. `속도Y -= 1` (중력 가속)
2. **터미널 벨로시티**: `속도Y < -8` 이면 `속도Y = -8`로 제한.
   높은 곳에서 낙하 시 속도가 너무 빨라지면 발판을 뚫고 지나감 방지.
3. `Y += 속도Y` (속도 적용)
4. 바닥 착지 판정 (2가지 분기):
   - **점프 후 착지** (`Y < ground_y` AND `점프중 == 1`):
     → Y 스냅, 속도Y=0, 점프중=0, **landing_costume으로 전환**
   - **바닥 유지** (`Y < ground_y` AND `점프중 == 0`):
     → Y 스냅, 속도Y=0 만 (코스튬 변경 없음)

## 왜 분리하는가?
바닥에서 매 프레임 코스튬을 "걷기1"로 리셋하면,
movement의 `next_costume()` 걷기 애니메이션이 작동하지 않음.
점프 착지 시에만 코스튬을 전환해야 걷기 애니메이션과 충돌 없음.

## 파라미터
| 이름 | 기본값 | 설명 |
|------|--------|------|
| `ground_y` | `GY(-140)` | 바닥 Y좌표. 스프라이트 하단이 이 높이에 맞춰짐. 캐릭터가 풀밭/땅 위에 더 붙어있는 느낌이 나도록 보정 (예: **GY+7**, 모든 스테이지 통일) |
| `landing_costume` | `None` | 착지 시 코스튬 (모든 스테이지: "걷기1") |

## 사용 변수
`속도Y`, `점프중`
