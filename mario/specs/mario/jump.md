# 마리오 - 점프 (Jump)

## 함수
`mechanics.mario_jump(m, V, velocity=14, jump_costume=None, sound="Jump")`

## 역할
스페이스 키로 점프. 이중 점프 방지.

## 동작
- 조건: 스페이스 눌림 AND 점프중==0
- 동작: 속도Y=14, 점프중=1, 점프 코스튬 전환, 사운드 재생
- 착지: `mario_physics`가 바닥 스냅 시 점프중=0 + 걷기 코스튬 복귀

## 점프 높이
- velocity=14 → 약 105px 상승

## 파라미터
| 이름 | 기본값 | 설명 |
|------|--------|------|
| `velocity` | `14` | 점프 초기 속도 |
| `jump_costume` | `None` | 점프 시 코스튬 (모든 스테이지: "점프1") |
| `sound` | `"Jump"` | 점프 사운드 |

## 사용 변수
`속도Y` (쓰기), `점프중` (읽기+쓰기)
