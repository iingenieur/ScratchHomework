# Stage 3 디자인

작성일: 2026-05-27
상태: 진행 중 (?블록 + 파이어 꽃 + 화이트 마리오 변신 추가 단계)

## 컨셉
쿠파 보스전 + 정통 마리오식 변신 메카닉.
마리오는 처음 일반 상태로 시작 → ?블록을 머리로 부수면 파이어 꽃이 나오고, 꽃을 먹으면 **화이트 마리오**로 변신해 Z키로 파이어볼 발사 가능.
파이어볼로 쿠파를 3번 맞히면 승리.

## 신규 메카닉 (이번 단계)

### ?블록 발판
- 정적 위치 sprite
- 마리오가 아래에서 머리로 부딪히면 코스튬 "물음표"→"빈블록" 전환 + 파이어 꽃 등장 broadcast
- 1회 발동 가드: 글로벌 변수 `꽃등장됨`(0/1)

### 파이어 꽃
- 초기 hide. "꽃등장" 브로드캐스트 수신 시 ?블록 위 등장
- 마리오 접촉 → "파이어변신" broadcast 발송 + hide

### 화이트 마리오 변신
- 일반 마리오 sprite + 화이트 마리오 sprite 두 개 (코스튬 cycle 충돌 회피)
- 변수 `파이어`(0/1): 일반/변신 상태
- 일반 마리오: `파이어==0`일 때 show, `==1`일 때 hide. 모든 메카닉 보유.
- 화이트 마리오: `파이어==1`일 때 show, `==0`일 때 hide. 위치/방향은 일반 마리오를 sensing으로 동기화. 코스튬은 자체 cycle (걷기 변수 공유).
- 파이어 상태에서 Z키로 파이어볼 발사 가능 (cond에 `파이어==1` 추가)

## 새 sprite

### 화이트 마리오 코스튬
- `mario3_white_walk_1.png` ~ `mario3_white_walk_6.png` (5장, 일반 마리오의 빨강을 흰색으로 변환)
- `mario3_white_jump_5.png` (점프)
- PIL로 빨강 픽셀(R > G+30 AND R > B+30 AND R > 100) → (240, 240, 240) 변환

### ?블록 sprite
- `svg_question_block()` 코스튬 "물음표"
- `svg_empty_block()` 코스튬 "빈블록"

### 파이어 꽃 sprite
- `svg_fire_flower()` 코스튬 "flower"

## 변수 / 브로드캐스트 추가
- 변수: `파이어` (0/1), `꽃등장됨` (0/1)
- broadcast: `꽃등장`, `파이어변신`

## 위치 (초안)
- 마리오 시작: (-150, GY+7) (기존)
- ?블록: x=0, y=-30 — 마리오 시작 옆에서 점프해 닿는 위치
- 파이어 꽃: ?블록 바로 위 (x=0, y=10)
- (쿠파, 피치 등 기존 보스전 요소는 그대로 유지)

## 기존 컨셉 유지
- 쿠파 좌우 패트롤
- 파이어볼로 쿠파 HP 0 → 피치 등장 → "고마워요 마리오!" → 클리어
