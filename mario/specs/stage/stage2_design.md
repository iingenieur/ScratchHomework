# Stage 2 재설계 (A/B 두 버전)

작성일: 2026-05-26
상태: 디자인 단계 (구현 전, 사용자 리뷰 대기)

## 컨셉
정통 마리오식 단일 화면 진행 스테이지. 좌→우로 진행해 오른쪽 끝 깃발에 도달하면 클리어.
Stage 1보다 적과 발판이 다양해지고, **가시 거북이**·**물음표 블록**·**움직이는 발판**이 신규 도입된다.

**최종 결정 (2026-05-27): A 버전 채택.** Stage2.sb3로 단일 빌드.
B 버전 코드(`build(has_fire=False)`)는 일단 유지하되 `main()`에서 호출하지 않음.

## 공통 사항 (A·B 동일)

### 화면 / 백드롭
- 480×360 단일 화면, 좌→우 진행
- 백드롭: 시작화면, 스테이지2, 게임오버, 클리어 (Stage 1 패턴)

### 레벨 레이아웃 (초안 — 좌표는 구현 시 미세 조정)
```
y=130  ────────────────────────────────────  🚩 깃발 (x=210)
y=80                                 [Plat4]   ← 가시거북이 패트롤
y=30                       [Plat3]
y=20                          [?블록]    ← A 전용, Plat2 위 공중
y=-20            [Plat2]
y=-70  [Plat1]
y=-140 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 바닥
            🐢                  🦔            ← 일반 거북이 / 가시 거북이
```
- **Plat1 (수평 이동)**: x=170 → x=-125, y=-70, 5.0초 주기. 마리오 시작 다리. 마리오 추종 ON.
- **Plat2 (고정)**: x=-195, y=0. Plat1 왼쪽 끝(x=-125)에서 점프해 닿는 위치.
- ?블록 (A 전용): x=-195, y=55 — Plat2 바로 위 공중.
- **Plat3 (고정)**: x=-65, y=30. Plat2에서 x≈130·y≈30 점프해 닿는 위치.
- **Plat5 (수직 이동, 신규)**: x=70 고정, y=70 ↔ y=30, 2.0초 주기. Plat3에서 점프해 닿고, Plat4로 점프해 갈 수 있는 다리.
- Plat4 (고정): x=200, y=30  (그 옆에 깃발 y=80)
- 일반 거북이는 Turtle1만 (바닥 좌측).
- Spiky2는 Plat4 위 (220 ↔ 180, y=88) — 깃발 직전 가드.

### 적 구성
| 적 | 위치 | 처치 |
|----|------|------|
| 일반 거북이 ×2 | 바닥 좌, Plat2 위 | 점프 밟기 → 등껍질 (Stage 1 메카닉 재사용) |
| 가시 거북이 ×2 | 바닥 우, Plat3 위 | 점프 밟아도 피격. **A만 파이어볼로 처치 가능**, B는 회피만. Plat4·깃발 영역엔 적 없음 (보상 구간) |

### 깃발
- `svg_flag()` 재사용
- x=210, y=130, size=150 (Stage 1과 동일 크기)
- 마리오가 닿으면 클리어 (mario_flag_clear 재사용)

### 공통 메카닉 (mechanics.py 재사용)
mario_physics, mario_movement, mario_jump, mario_platform_landing,
mario_platform_block, mario_side_hit, mario_stomp(일반 거북이용),
mario_gameover, mario_flag_clear, mario_invincibility, hide_on_end.

## A 버전 전용 (Stage2A.sb3)

### 신규 메카닉: 물음표 블록
- 위치: x=-60, y=20 (Plat2 바로 위 공중)
- 코스튬 2장: "물음표" (초기), "빈블록" (사용 후)
- **머리 충돌 판정** (Mario가 아래→위 방향으로 충돌):
  - 조건: `touching(?블록)` AND `속도Y > 0` AND `마리오 y < 블록 y` AND **`?블록 코스튬 == "물음표"`** (1회 발동 가드)
  - 처리 (마리오 측 스크립트에서):
    1. broadcast "꽃등장" (블록·꽃 측에서 수신)
    2. 마리오 속도Y = 0 (머리 막힘, 기존 mario_platform_block 패턴 재사용)
  - ?블록 측 "꽃등장" hat: 코스튬을 "빈블록"으로 전환
- **위에서 착지**도 가능 (일반 발판처럼 mario_platform_landing 메카닉 적용 — Plat2 패턴 재사용)
- 1회 발동 가드는 **코스튬 비교**로만 처리 (별도 변수 도입 안 함, 상태가 코스튬에 일원화)

### 신규 스프라이트: 파이어 꽃
- `svg_flower()` 신규 작성 (빨강+초록, 마리오풍)
- 초기 상태: `hide`
- "꽃등장" 브로드캐스트 수신 시:
  - 물음표 블록 바로 위 위치로 이동 (`block_x`, `block_y + 20`)
  - `show()`
- 마리오 접촉 시:
  - broadcast "파이어변신"
  - `hide()`

### 마리오 파이어 변신
- 변수 `파이어` (0/1) 신규
- "파이어변신" 수신 → `파이어 = 1`, 코스튬을 파이어 마리오 계열로 전환 (예: "파이어걷기1")
- **지속 시간: 무한** (재시작 전까지 유지)
- 게임 재시작 시 (`스테이지2` 브로드캐스트 init) → `파이어 = 0` 리셋

### 파이어볼 (Stage 3 메카닉 재사용)
- Z키 hat → 마리오 위치에서 파이어볼 발사
- 단, **`파이어 == 1`일 때만** 발사 가능 (게임상태 가드 + 파이어 가드)
- 파이어볼 sprite는 Stage 3의 fireball SVG 재사용
- 적(일반 거북이·가시 거북이)에 닿으면:
  - 적의 "맞음" 브로드캐스트 발송 → 적이 hide

### A 전용 스프라이트
- 물음표 블록 (`question_block`)
- 파이어 꽃 (`fire_flower`)
- 파이어볼 (`fireball`)

## B 버전 전용 (Stage2B.sb3)

- 물음표 블록·파이어 꽃·파이어볼 **없음**
- 마리오 Z키 hat 없음, `파이어` 변수 없음
- 가시 거북이는 점프 밟아도 피격이므로 **회피만 가능**
- 깃발 도달이 클리어의 유일한 길
