# 발판 - 착지 (Platform Landing)

## 함수
`mechanics.mario_platform_landing(m, V, plat_positions)`

## 역할
마리오가 위에서 낙하하며 발판 위에 착지하는 판정

## 착지 조건 (3중 AND)
1. `touching(발판)` — 발판과 접촉 중
2. `속도Y < 0` — 낙하 중
3. `Y > 발판Y + 10` — 마리오가 발판 위에 있음

## 착지 처리
1. `change_y(1)` — 중력(-1) 상쇄하여 안정 유지
2. `속도Y = 0` — 낙하 정지
3. `점프중 = 0` — 점프 가능 복귀
4. 코스튬 → "걷기1"

## 왜 change_y(1)인가?
`set_y(발판Y)`는 발판 두께/크기에 따라 뚫고 내려감.
`change_y(1)`은 현재 위치에서 중력을 상쇄하여 떨림 없이 안정.

## 사용 변수
`속도Y`, `점프중`
