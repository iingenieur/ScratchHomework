# 움직이는 발판 (Moving Platform)

## 역할
Stage 2 신규. 좌우로 왕복 이동하는 발판. 정적 발판 사이의 다리 역할.
정통 마리오의 컨베이어/이동 발판 감각을 살림.

## 동작
- glide 블록으로 `(x1, y1) ↔ (x2, y2)` 사이 왕복 (forever)
  - x1≠x2, y1=y2 → 수평(좌우) 이동
  - x1=x2, y1≠y2 → 수직(위아래) 이동
- 기본: 마리오 추종 없음 (발판이 움직이면 마리오는 그 자리에 머물고 발판이 멀어지면 낙하)
- **Plat1 한정 — 마리오 추종**: 마리오가 Plat1 위에 있으면(`touching` + `속도Y==0`) 발판의 한 프레임 x 변화량(`Plat1_dx`)만큼 마리오 x가 함께 이동. 마리오는 가만히 있어도 발판과 같이 흘러간다.

## 메카닉 연동
- 마리오 측: 기존 `mario_platform_landing`, `mario_platform_block` 사용
  - **정적 평균값** (`(y1+y2)/2`)을 `plat_y`로 사용
  - 발판 실제 위치와 약간 다를 수 있지만 게임 동작은 안정
  - x는 무관 (touching만 봄)
- 발판 측: 추가 변수 없음, glide 무한 반복

### Plat1 추종 구현 (필요한 메카닉)
글로벌 변수 두 개로 발판의 프레임당 x 변화량을 마리오에 전달.

| 변수 | 의미 |
|------|------|
| `Plat1_x_prev` | 직전 프레임 Plat1의 x 좌표 (초기 120) |
| `Plat1_dx` | 한 프레임 x 변화량 (초기 0) |

Plat1 sprite 두 번째 forever:
1. `Plat1_dx = (자기 x) - Plat1_x_prev`
2. `Plat1_x_prev = (자기 x)`

마리오 forever (move 처리 다음):
- `if touching(Plat1) AND 속도Y == 0: change_x(Plat1_dx)`

## 위치 (Stage 2 — 2026-05-27 갱신)
Plat1만 이동 발판. Plat2·Plat3·Plat4는 고정.

| 이름 | (x1,y1) | (x2,y2) | 속도 | 역할 |
|------|---------|---------|------|------|
| Plat1 | (170, -70) | (-125, -70) | **5.0초** | 수평. x=170에서 시작 → x=-125까지. **마리오 추종 ON** |
| Plat5 | (70, 70)   | (70, 30)    | 2.0초 | **수직(위→아래)**. Plat3 → Plat4 다리. 추종 OFF (정적 plat_y=50) |

## 크기
75% (정적 발판과 동일)
