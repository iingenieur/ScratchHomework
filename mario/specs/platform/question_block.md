# 물음표 블록 (Question Block)

## 역할
Stage2A 전용. 마리오가 아래에서 머리로 부딪히면 아이템(파이어 꽃)을 출현시키는
정통 마리오 메카닉. 위에서는 일반 발판처럼 착지 가능.

## 동작
### 위에서 착지 (양면 발판)
- `mario_platform_landing` 메카닉 적용 — 마리오가 낙하 중 위에서 닿으면 착지
- `mario_platform_block` 메카닉 **부분 적용** — 머리 막힘 처리는 ?블록 자체에서 직접 처리(아래 참고)

### 아래에서 머리 충돌 — 책임은 **?블록 sprite의 forever 루프**
※ 마리오 측 `mario_platform_block`에는 QBlock을 **포함하지 않는다**.
   포함하면 마리오 측에서 속도Y=0이 먼저 적용되어 ?블록 forever 감지 시점에는 이미 0이라 발동 실패.

?블록 sprite forever 루프:
- 조건: `touching("Mario")` AND `속도Y > 0` AND `꽃등장됨 == 0`
- 처리 (모두 ?블록 측에서 실행, 글로벌 변수로 마리오 상태도 함께 갱신):
  1. `꽃등장됨 = 1` (1회 발동 가드)
  2. `broadcast "꽃등장"`
  3. `코스튬 → "빈블록"`
  4. `속도Y = 0` (마리오 머리 막힘 — 글로벌 변수)

### 1회 발동 가드
- 글로벌 변수 `꽃등장됨` (0=초기, 1=사용 후) 사용
- 코스튬 비교 대신 변수 가드 (Scratch에 코스튬 비교 헬퍼 미존재)
- 게임 재시작 시 `꽃등장됨 = 0` 리셋

## 코스튬
| 이름 | 용도 |
|------|------|
| 물음표 | 초기 (아이템 보유) |
| 빈블록 | 사용 후 (회색) |

## 스프라이트
- `svg_question_block()` — 노란 ?블록
- `svg_empty_block()` — 회색 빈 블록

## 위치
- x = -195, y = 55 — Plat2 (x=-195, y=15) 바로 위 공중. 마리오가 Plat2에서 점프해 머리로 칠 수 있는 높이.

## 크기
75% (일반 발판과 동일)
