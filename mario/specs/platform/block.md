# 발판 - 아래에서 막힘 (Platform Block)

## 함수
`mechanics.mario_platform_block(m, V, plat_positions)`

## 역할
발판 아래에서 점프할 때 발판을 뚫고 올라가지 못하게 막음

## 막힘 조건 (3중 AND)
1. `touching(발판)` — 발판과 접촉 중
2. `속도Y > 0` — 위로 올라가는 중
3. `Y < 발판Y` — 마리오가 발판 아래에 있음

## 막힘 처리
`속도Y = 0` — 상승 정지 (이후 중력에 의해 자연스럽게 낙하)

## 착지와의 차이
| | 착지 (landing) | 막힘 (block) |
|--|--------|-------|
| 방향 | 위→아래 (낙하) | 아래→위 (상승) |
| 조건 | 속도Y < 0 + Y > 발판Y | 속도Y > 0 + Y < 발판Y |
| 처리 | change_y(1) + 점프중=0 | 속도Y=0 만 |

## 사용 변수
`속도Y`
