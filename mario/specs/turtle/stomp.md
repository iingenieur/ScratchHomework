# 거북이 - 밟기 반응 (Stomp Response)

## 동작
거북이가 밟기 브로드캐스트를 수신하면:
1. `stop_other()` — 순찰 스크립트 중지
2. 코스튬을 "shell"(등껍질)로 변경
3. **`goto_front()`** — 발판 등 다른 스프라이트에 가려지지 않도록 최상단 레이어로 이동
4. **`set_y(-7)`** — Turtle2 한정: 발판 위에 등껍질이 자연스럽게 놓이도록 Y 보정
5. 2초 대기
6. 숨김 (hide)

## 왜 goto_front?
Turtle2가 Plat2 위에서 순찰하다가 등껍질로 변하면, 스프라이트 레이어 순서상
Plat2(layerOrder 더 큼)가 등껍질을 가려서 보이지 않게 됨. 등껍질이 보이도록
레이어를 앞으로 보냄.

## 브로드캐스트
- 수신: "밟기N" (N=거북이 번호) — 마리오의 `mario_stomp`이 발송
- 수신: "스테이지1" — 순찰 재시작 + 코스튬 리셋

## 연동
- 마리오의 `mario_stomp()` → 낙하 중 접촉 → "밟기N" 브로드캐스트 발송
- 마리오의 `mario_side_hit()` → 낙하 아닐 때 접촉 → 하트 감소
