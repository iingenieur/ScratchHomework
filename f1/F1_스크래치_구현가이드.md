# F1 그랑프리 레이서 - 스크래치 구현 가이드

이 문서는 스크래치(Scratch)에서 F1 레이싱 게임을 만들기 위한 단계별 구현 가이드입니다.

---

## 변수 목록 (모든 스프라이트에서 사용)

| 변수명 | 초기값 | 설명 |
|--------|--------|------|
| `연료` | 100 | 연료 게이지. 시간에 따라 감소, 0이면 게임오버 |
| `점수` | 0 | 플레이 점수. 시간/거리에 따라 증가 |
| `현재랩` | 1 | 현재 랩 번호 (1~3) |
| `랩거리` | 0 | 현재 랩에서 달린 거리. 목표 도달 시 랩 증가 |
| `게임상태` | "start" | 게임 상태: start / countdown / playing / gameover / win |
| `속도` | 3 | 장애물/배경 스크롤 속도 (랩별 증가) |
| `DRS활성` | 0 | DRS 부스터 활성 여부 (0=비활성, 1=활성) |

---

## 스프라이트별 구현

### 1. 배경 (Stage)

**배경 종류:**
- `시작화면`: 게임 타이틀 "F1 그랑프리 레이서" + "스페이스를 눌러 시작" 문구
- `트랙`: F1 도로 배경 (회색 도로 + 흰색 차선)
- `게임오버`: "GAME OVER" + 점수 표시
- `승리`: "CHAMPION!" + 최종 점수 표시

**블록 로직:**
```
[초록 깃발 클릭했을 때]
배경을 [시작화면]으로 바꾸기
[게임상태]를 "start"로 정하기
[연료]를 100으로 정하기
[점수]를 0으로 정하기
[현재랩]을 1로 정하기
[랩거리]를 0으로 정하기
[속도]를 3으로 정하기

[스페이스 키를 눌렀을 때]
만약 [게임상태] = "start" 이라면
  배경을 [트랙]으로 바꾸기
  [게임상태]를 "countdown"으로 정하기
  [시작신호] 방송하기
끝

["레이싱시작" 방송을 받았을 때]
[게임상태]를 "playing"으로 정하기
[BGM 재생] 방송하기
[연료감소시작] 방송하기
[적생성시작] 방송하기
[점수증가시작] 방송하기
```

**블록 로직:**
```

숨기기

["레이싱시작" 방송을 받았을 때]

    나 자신의 클론 만들기
    (0.3)초 기다리기
  끝
끝

[클론이 시작될 때]
보이기

  y좌표를 [속도] × (-1) 만큼 바꾸기

  끝

### 3. 신호등 (TrafficLight)

**모양 4개:**
- `빨강1`: 빨간불 1개 켜짐
- `빨강2`: 빨간불 2개 켜짐
- `빨강3`: 빨간불 3개 켜짐
- `초록`: 모두 초록불 + "GO!"

**블록 로직:**
```
[초록 깃발 클릭했을 때]
숨기기

["시작신호" 방송을 받았을 때]
보이기
x: (0) y: (50)으로 이동하기
크기를 (150)%로 정하기

모양을 [빨강1]로 바꾸기
[Beep] 소리 재생하기
(1)초 기다리기

모양을 [빨강2]로 바꾸기
[Beep] 소리 재생하기
(1)초 기다리기

모양을 [빨강3]로 바꾸기
[Beep] 소리 재생하기
(1)초 기다리기

모양을 [초록]로 바꾸기
[Vroom] 소리 재생하기
(0.5)초 기다리기

숨기기
[레이싱시작] 방송하기
```

```

    만약 <[오른쪽 화살표] 키가 눌렸는가?> 이라면
      만약 x좌표 < (150) 이라면
        x좌표를 (5) 만큼 바꾸기
      끝
    끝
    만약 <[왼쪽 화살표] 키가 눌렸는가?> 이라면
      만약 x좌표 > (-150) 이라면
        x좌표를 (-5) 만큼 바꾸기
      끝
    끝
  끝
끝
```

### 9. 게임 시스템 (Stage 스크립트에 추가)

    끝
  끝
끝
```

#### 점수 & 랩 시스템
```
["점수증가시작" 방송을 받았을 때]
무한 반복하기
  만약 [게임상태] = "playing" 이라면
    (0.1)초 기다리기
    [점수]를 (1) 만큼 바꾸기

      [속도]를 (1) 만큼 바꾸기    ← 랩마다 속도 증가
      만약 [현재랩] > (3) 이라면
        [게임상태]를 "win"으로 정하기
        배경을 [승리]로 바꾸기
        모두 멈추기
      끝
    끝
  끝
끝
```

## 만드는 순서 (추천)

1. **배경 만들기**: 시작화면, 트랙, 게임오버, 승리 배경 4개 그리기
2. **내 F1 차 만들기**: 스프라이트 그리기 + 좌우 이동 코딩
3. **도로 줄무늬**: 클론으로 스크롤 효과 만들기
4. **적 차량**: 느린 차 먼저 만들고, 복제해서 빠른 차 만들기
5. **연료 시스템**: 연료 변수 + 감소 로직 + 게임오버 처리
6. **연료 아이템**: 먹으면 연료 회복
7. **랩 시스템**: 거리 측정 + 랩 증가 + 승리 조건
8. **신호등 카운트다운**: 시작 연출 추가
9. **DRS 부스터**: 속도 증가 효과 추가
10. **사운드**: 배경음악 + 효과음 추가
11. **테스트 & 밸런싱**: 연료 감소 속도, 적 생성 빈도, 랩 거리 조절

## 스크래치 팁

- **클론 제한**: 스크래치는 최대 300개 클론만 허용. 화면 밖의 클론은 반드시 삭제할 것.
- **속도 조절**: `속도` 변수 하나로 배경, 적, 아이템의 이동 속도를 통일하면 난이도 조절이 쉬움.
- **충돌 감지**: `~에 닿았는가?` 블록 사용. 색상 감지보다 스프라이트 감지가 더 정확함.
- **소리**: 스크래치 라이브러리에서 "Drive Around", "Vroom", "Pop" 등을 활용하거나 직접 녹음 가능.
- **그림**: 스프라이트는 스크래치 그림판에서 직접 그리거나, 외부 이미지를 업로드할 수 있음.
